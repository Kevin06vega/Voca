# Resultados de comprobación

`android.xml` y `unitarias.xml` conservan los resultados de las pruebas automáticas realizadas durante la implementación. Se omitió el atributo de nombre de equipo (`hostname`) del XML de pruebas unitarias para compartir el archivo. Los recuentos, tiempos, nombres de pruebas y resultados se conservan.

`resumen.json` distingue los resultados automáticos de las comprobaciones manuales de voz reportadas por el usuario. Las cinco pruebas manuales del emulador no constituyen una evaluación de accuracy ni sustituyen la comprobación pendiente en un Android físico. `VERIFICACION.md`, en la raíz del proyecto, explica el alcance de cada comprobación.
